Changelog

Newest first.

0.1.6 2026-08-22
  • Design system tightening: one spacing scale, five type steps, one radius, one hairline, one shadow. Every margin and font size now comes from a token.
  • Preset chips load a worked example for each circuit in one click.
  • Bode plots read out any point on hover, snapping to the nearest swept sample.
  • Keyboard support throughout: arrow keys move between circuits and step component values, Enter runs, Esc dismisses an error.
  • About page says who builds this.
0.1.5 2026-08-22
  • Circuit registry: every circuit is one catalogue entry describing its parameters, netlist, measurement and analytic checks. The page builds its forms from that catalogue.
  • RC high-pass filter, with the corner measured from the passband down.
  • Series RLC band-pass, with resonance found by quadratic interpolation and Q from the two −3 dB skirts.
  • Inverting amplifier on a single-pole op-amp macromodel, showing gain-bandwidth as a real trade rather than a formula.
0.1.0 2026-08-22
  • RC low-pass circuit, selectable alongside the DC divider from a mode switcher.
  • AC sweep through ngspice: 20 points per decade, three decades either side of the corner, read back with wrdata.
  • Bode plot on the paper panel — magnitude and phase over log frequency, with the corner marked.
  • -3 dB extraction by interpolation in log frequency, checked against 1/(2πRC).
0.0.1 2026-08-22
  • Visual identity: dark instrument chrome, paper datasheet figure, copper accent, monospace numerics.
  • Added the About and Changelog pages behind a shared nav and footer.
  • Live SVG schematic that redraws as you type and annotates the out node after a run.
  • Static asset routing: GET is served from a strict whitelist, and request paths never touch the filesystem.
0.0.0 2026-08-22
  • Resistor divider simulated through real ngspice, with the analytic value shown only as a check.
  • Standard-library web server and a single-page interface.
  • 74 tests covering netlist construction, output parsing, request validation, and a live simulator run.
