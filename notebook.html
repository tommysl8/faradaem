Notebook

Every run this machine has made, written down as it happened. Engineers keep lab notebooks badly; this one is a side effect of the provenance rule, so it cannot be forgotten.

The notebook is written by the local simulator as it runs. It is a reading of the ledger on the machine doing the work, and this published demo has no ledger, because it has never run anything.

There is no ledger here

Every Faradaem run appends to a ledger: what was tried, what was measured, what was decided, and the provenance that makes a number evidence rather than an assertion. The ledger lives beside the simulator, on the machine that ran it, never on a server. So there is nothing for this page to read, and nothing it could honestly show you.

Run Faradaem locally and this page fills itself: every run newest first, its simulation count taken at the subprocess boundary, its stored datasheets, and any damaged lines a crash left behind, shown rather than hidden.
